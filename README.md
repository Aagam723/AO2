Part 1: Directions on Using WebStorm
To download and use Webstorm, do this:
1. Go to https://www.jetbrains.com/webstorm/ and download the installer
2. Install it and launch the app
3. Link it to your existing vscode
4. Link it with your repository by cloning it (put the repository url after you press the create a clone button
5. Press clone after doing that and selecting where the repository will go on your device
6. After you're done making changes, use the commit tab to save your changes
7. Write your commit message and press commit
