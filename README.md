Part 1: Directions on Using WebStorm
To download and use Webstorm, do this:
1. Go to https://www.jetbrains.com/webstorm/ and download the installer
2. Install it and launch the app
3. Link it to your existing vscode
4. Link it with your repository by cloning it (put the repository url after you press the create a clone button
5. Press clone after doing that and selecting where the repository will go on your device
6. After you're done making changes, use the commit tab to save your changes
7. Write your commit message and press commit
8. Press the 3 horizontal line buttons on the top left, then press git, and then press push and it will push the commits to github.


Part 2: Glossary

**Branch**: A separate version of a project used to work on code without affecting the main files.

**Clone**: A local copy of a repository from a server.

**Commit**: A snapshot of your changes saved to the project history with a message describing the changes made.

**Fetch**: Downloading updates from a remote repository without merging them.

**GIT**: A tool used to track changes in code files.

**Github**: A cloud-based website/platform that hosts and manages Git repositories.

**Merge**: Combining changes from different branches into one.

**Merge Conflict**: An error when code changes in two versions intefere with each other and cause an error.

**Push**: Uploading your local commits to the GitHub server.

**Pull**: Fetching and merging changes from the server to your computer.

**Remote**: The project version hosted on a network or the internet.

**Repository**: A folder storing project files and their history.
